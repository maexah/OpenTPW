Get Started

How to get OpenTPW running on your computer.

i You need your own copy of the game to ride. A disc or a disc image will do.

Read this first

  • OpenTPW is not finished. You can look around, but you cannot play a whole game yet.
  • There is no ready download yet. Today you build it yourself from its code. The steps are below.
  • You need your own copy of the game. OpenTPW holds no game files.
  • It is tested on Linux. It also builds for Windows and Mac. Windows has not been tried lately. Mac has never been tried.

See what runs today

Five steps

  1. Copy your game disc

    Put the game disc in your computer. If you have a disc image (an .iso file), open that.

    Copy everything on it into a new folder. For example, a folder called Sim Theme Park in your Documents.

  2. Install .NET 10

    OpenTPW is built with a free tool from Microsoft called the .NET 10 SDK.

    Get the .NET 10 SDK

    On Linux you also need a Vulkan driver. If OpenTPW will not start, see "If something goes wrong" below.

  3. Get the code

    Open a terminal and type:

    git clone https://github.com/maexah/OpenTPW.git
cd OpenTPW

    No git? This fork's GitHub page has a green Code button with "Download ZIP". Unpack the file, and open your terminal in the folder it makes.

  4. Build it

    dotnet build source/OpenTPW.sln

    This also fetches everything else OpenTPW needs.

  5. Run it

    Tell OpenTPW where your copy of the game is. Keep the quote marks.

    dotnet source/OpenTPW/bin/Debug/net10.0/OpenTPW.dll --game "/path/to/Sim Theme Park"

    The lobby opens, with its four islands. Lost Kingdom is the one to visit.

Keys to know

Escape
Opens the game menu. In a park it first lets go of what you hold.
[ and ]
Move between the islands.
X
Holds the lobby camera still.
C
In a park: walk on the ground and look around. Press again to go back.
Left, Right
Turn the park camera.
Mouse wheel
Zoom the park camera.
F2
Hides the buttons and panels.
Ctrl and H
Shows or hides the help bar.

If something goes wrong

  • "Theme Park World was not found."

    Check the folder you gave in step 5. OpenTPW lists every folder it looked in.

  • "Its names have been cut short."

    The disc was copied in a way that shortened the file names. Delete the folder. Copy the disc again by dragging the files in your file manager.

  • It stops before a window opens.

    If it says it could not load a library, install your system's Vulkan loader and the driver for your graphics card.

  • On Linux, the window is an odd size, or it says "No available video device".

    This can happen on a Wayland desktop. Install XWayland and try again.

  • There is no sound.

    OpenTPW warns you and carries on. The game still runs.

Something else? Guest Services has more answers.

Which game disc?

OpenTPW is tested with the American disc, called Sim Theme Park.

The disc sold in other countries is called Theme Park World. It should work too, but nobody has tested it. If you try it, please tell the project how it went.

OpenTPW is a fan project. It rebuilds the game Theme Park World. In America the game is called Sim Theme Park.

It holds no game files. You need your own copy of the game to play.

It is not made or approved by the game's makers or publishers.
