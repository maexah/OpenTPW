Ride Status

How much of OpenTPW is built, and what is being built next.

What you can do today

You can

  • Open the park that comes with Lost Kingdom.
  • Watch guests arrive, queue, ride and buy drinks.
  • Lay paths, buy rides and hire staff.

You cannot yet

  • Save a park.
  • Finish a game.
  • Open a park in Wonder Land, Halloween World or Space Zone.

The numbers below show how much is built. Each card says where its number comes from.

  • 3 of 31

    Lost Kingdom rides, shops and sideshows running

    Guests can use 3 of the 31 things in Lost Kingdom today. This list is kept by hand. See which.

  • 77 of 106

    Script commands built

    The game's rides, shops and sideshows are run by small scripts. The game has 106 script commands. OpenTPW can carry out 77 of them. A small program counts this from the code.

  • 0

    Known gaps left

    A gap is a place where the game asks for something OpenTPW has not built yet. A small program counts the gaps that have a fixed name in the code. A few are named in other ways and are not counted, so the real number is a little higher. It goes down when a gap is filled, and up when a new one is found.

OpenTPW is a fan project. It rebuilds the game Theme Park World. In America the game is called Sim Theme Park.

It holds no game files. You need your own copy of the game to play.

It is not made or approved by the game's makers or publishers.

OpenTPW was started by Alex Guthrie and its contributors. This site follows a fork of their work. The original project on GitHub
