## 3. New: things loaded from the save cannot be clicked

The world pick resolves a thing as `state.CellAt( x, y ).Occupant` (`ParkPicking.cs:129`). `Occupant`
is written by `ParkBuilding.Buy` (`ParkBuilding.cs:242`) and by peeps standing on a cell
(`ParkState.cs:551`). Nothing writes it for the save's own objects when a park loads. So every
pre-placed thing picks as thing 0 and no window opens. There is no hover code anywhere in `source/`,
so "nothing highlights" is unbuilt rather than broken.
