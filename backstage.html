Code

Staff only? Not here. Come and see how the park is built.

This page is for people who want to read the code, learn how the old game works, or help.

  • The code

    All of this fork of OpenTPW is on GitHub. It is written in C#. Anyone may read it, copy it and change it, under the MIT licence.

    This fork on GitHub

  • Where it came from

    OpenTPW was started by Alex Guthrie and its contributors. The code this site shows is a fork: a copy that carries their work on. It is not the original project's own site.

    The original project on GitHub

  • The file format notes

    The old game keeps its models, pictures, sounds and saved parks in its own kinds of file. The project writes down what it learns about each kind, so that anyone can read them.

    The file format notes

  • Report a fault

    Did something break, or look different from the old game? Please say so. Tell us what you did, what you saw, and which computer you use.

    Report a fault on GitHub

How to help

  1. Make your own copy of this fork on GitHub.
  2. Make a branch for your change. Name it YourName/WhatItChanges.
  3. Build it and run the tests. The two commands are below.
  4. Open a pull request when you are ready.
dotnet build source/OpenTPW.sln
dotnet test source/OpenTPW.sln

Most tests read the real game files. Without the game they are skipped.

You do not have to write code to help. Trying OpenTPW on Windows, on a Mac, or with the Theme Park World disc, and saying how it went, is a real help.

About this website

  • It holds no files from the game. Its drawings and its 3-D islands are new, made in code.
  • The only words from the game are its names, and one short quote from its advisor on each land's page.
  • The pictures under "See it running" are OpenTPW itself, running. What they show is the game's own art.
  • It makes no sound. Your browser loads nothing from any other website.
  • The numbers on Ride Status are read from the project's own notes each time this website is updated.
  • Its own code and drawings are free to read, copy and change, under the MIT licence.
  • The 3-D islands are drawn with three.js. The lettering is Boogaloo, Itim, Atkinson Hyperlegible and OpenDyslexic. All are free to use.
